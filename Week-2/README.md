# Week 2: Visualize genomic data

## Assignment Overview

This week's assignment focuses on downloading genomic data and learning to visualize it using bioinformatics tools. You'll work with FASTA files, annotation files, and explore genome visualization techniques.

## General Requirements

- Create a new directory for Week 2 of the course
- Put your `Makefile` and `README.md` files into this directory
- Publish the information so that it is visible via GitHub
- Submit the URL to your directory on GitHub

## Assignment Instructions

### Part 1: Download Genomic Data

Download a FASTA and an annotation file (GFF/GTF file) for a genome from a repository.

- [Download genomic data from a repository](https://www.ncbi.nlm.nihm.gov/)
- [Visualize genomic data in IGV](http://software.broadinstitute.org/software/igv/)

Answer the questions posed in the body of each of the pages above.
