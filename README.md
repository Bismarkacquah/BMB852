# BMB852: Bioinformatics Course Assignments

This repository contains all assignments and projects for the BMB852 Bioinformatics course.

## Course Structure

Each folder contains that week's assignment, results, and supporting files.

### Weeks

- **[Week 1](Week-01/)**: System Setup and UNIX Command Line Basics
- **[Week 2](Week-02/)**: Bioinformatics Tools and Data Formats
- **[Week 3](Week-03/)**: Sending Suggestions with Forking and Repository Assessment
- **[Week 4](Week-04/)**: Obtaining FASTQ data and evaluating read quality
- **[Week 5](Week-05/)**: BAM alignment and coverage analysis
- **[Week 6](Week-06/)**: Structural variant analysis
- **[Week 7](Week-07/)**: Variant calling, IGV views, and VCF statistics
- **[Week 8](Week-08/)**: Five-sample variant-effect analysis
- **[Week 9](Week-09/)**: Design-driven variant calling for ten samples
- **[Week 10](Week-10/)**: Moss ChIP-seq peak calling and replicate comparison
- **[Week 11](Week-11/)**: RNA-seq coverage and gene expression assessment in IGV
- **[Week 12](Week-12/)**: Transcript-level and gene-level RNA-seq count matrices
