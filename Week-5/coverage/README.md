# Week 5 coverage files

`ERR8982185.coverage.tsv` contains the per-reference Samtools coverage report.
`ERR8982185.depth_summary.json` contains the recalculated genome-wide and
covered-base depth statistics. These small results accompany the report.

The large `ERR8982185.depth.tsv` and sparse `ERR8982185.covered_depth.tsv`
are generated locally and ignored by Git. Commands to recreate and summarize
them are in the parent [assignment report](../README.md).
